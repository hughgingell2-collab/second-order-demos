How OpportunityScout works

This page is live data, not a mockup. Every opportunity links to its real official page, and a scraper checks those pages every week.

The loop

  1. A curated catalog of opportunities lives in scout/opportunities.yaml — each entry carries its official admissions/apply page URL.
  2. Every Tuesday morning (AEST) a GitHub Actions job runs scout/scraper.py, which fetches each watched page, pulls out the text around deadline-related phrases ("applications close", "apply by", "deadline"…), extracts any dates, and compares against last week's snapshot.
  3. If a page changed — a new deadline appeared, applications opened, a round closed — the job opens a GitHub issue in this repo listing exactly what changed. GitHub emails you the issue, so notifications arrive with zero extra infrastructure.
  4. The job also regenerates this dashboard's data, so "days left" badges and "page changed" flags stay current.

Reading the badges

  • Nd left — days until the listed deadline (red < 30, amber < 90, blue beyond).
  • Rolling / batch — no fixed deadline; applications reviewed continuously or in batches.
  • Closed — next cycle — this cycle's deadline passed; the scraper will flag when the next one is published.
  • page changed — the scraper detected a change on the official page within the last 3 weeks. Click the row for the dates it spotted.
  • fetch error — the page moved or blocked the scraper; the weekly issue includes these so links can be fixed.

Adding or removing opportunities

Edit scout/opportunities.yaml (or ask Claude to), then run python scout/scraper.py. The dashboard, the watch-list and the notifications all follow from that one file. Set watch: false on an entry to keep it listed without scraping it.

Off-the-shelf tools that do parts of this

  • changedetection.io — open-source page-change watcher; the closest generic equivalent to this scraper.
  • ProFellow — searchable database of ~2,900 fellowships with a free account.
  • FindAMasters — masters-program search with saved-search email alerts.
  • F6S — startup-program directory with application deadlines and alerts.
  • Visualping / Distill.io — commercial page-change monitors with free tiers.

None of them combine a profile-matched shortlist across grad programs + scholarships + incubators with change alerts — which is why this exists.

Honest limitations

  • Some sites render deadlines with JavaScript or block bots; those entries show "fetch error" and need a manual check (the weekly issue lists them).
  • Date extraction is regex-based — it flags changes reliably, but always confirm a deadline on the official page before planning around it.
  • The catalog is curated, not exhaustive: it's the shortlist that fits this profile, not a directory of everything.
