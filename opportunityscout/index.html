How OpportunityScout works

This page is live data, not a mockup. Every opportunity links to its real official page, a scraper checks those pages weekly, and your application record drives what you see.

The loop

  1. A curated catalog lives in scout/opportunities.yaml — five categories: further study, startup programs & funding, pitch events (Sydney), pitch events (San Francisco), and other opportunities. Each entry: what it is in two sentences, what to prepare in one, and the official URL.
  2. Every Tuesday morning (AEST) a GitHub Actions job fetches each watched page, pulls the text around deadline/apply phrases, extracts dates, and diffs against last week.
  3. On any change it opens a GitHub issue — which GitHub emails you. Next to each opportunity in that email are two buttons: ✅ I applied and 🚫 Not interested.
  4. Clicking a button opens a pre-filled GitHub issue; press Submit and a second workflow records it in scout/status.yaml, updates this dashboard (applied badge / hidden), closes the issue, and stops alerting you about hidden items.

Your application record

The record lives in scout/status.yaml in the repo — seeded from your startup notes (e.g. the Antler residency application with TerraCheck) and updated by the feedback buttons. Rows you've applied to carry an applied ✓ badge; hidden rows disappear from alerts and are dimmed here (tick "show hidden" to see them). The same two buttons appear in every row's detail panel.

Reading the badges

  • Nd left — days until the listed deadline (red < 30, amber < 90, blue beyond).
  • Rolling / recurring — no fixed deadline; apply anytime or the event recurs.
  • Closed — next cycle — this cycle passed; the scraper flags when new dates appear.
  • page changed — the scraper saw the official page change in the last 3 weeks.
  • fetch error — the page moved or blocked the scraper; the weekly issue lists these.

Honest limitations

  • Some sites render deadlines with JavaScript or block bots; those show "fetch error" rather than silently going stale.
  • Dates marked "expected" are pattern-based projections from the previous cycle — always confirm on the official page.
  • The catalog is a curated shortlist for this profile (~10 per category), not a directory of everything.
